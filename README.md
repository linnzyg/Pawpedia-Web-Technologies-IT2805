## How to run
### Prerequisites
Make sure you have Node.js 22.5+ and npm 10.8+ installed.

### Install dependencies:
Clone the project in your favorite IDE, navigate to the folder, and then install dependencies using:
```bash
npm install
```

### Start the development server:

```bash
npm run dev
```
